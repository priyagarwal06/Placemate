*PlaceMate* : Campus Placement Management System, is a C++ based placement management system developed using Object Oriented Programming concepts.
The main aim of this project is to simplify and organize the college placement process for students, recruiters, and the placement cell.
The system allows students to register, log in, update their academic details like CGPA and skills, upload resume information, check which companies they are eligible for, apply to them, and track their placement status.
Recruiters can log in to the system, post job opportunities, define eligibility criteria such as CGPA and branch, and view or shortlist eligible students.
The admin (placement cell) manages the entire system by adding or updating student and recruiter details, approving company postings, and monitoring the overall placement activities.
This project uses OOP concepts such as classes, inheritance, encapsulation, and polymorphism to make the system well-structured and easy to manage. *PlaceMate* provides a simple and efficient way to simulate a real-life placement process.
